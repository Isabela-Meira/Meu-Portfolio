# 🌿 Portfólio — Isabela Silva Meira

## 👩‍💻 Sobre o projeto

Este projeto consiste no desenvolvimento do meu portfólio pessoal, criado para apresentar meu perfil, minhas habilidades e alguns dos projetos desenvolvidos durante minha jornada de aprendizado em ADS.

## 🌟 Recurso adicional desenvolvido

Foi implementada uma animação interativa nos cards dos projetos.

Ao passar o cursor do mouse sobre um card, ele se movimenta suavemente para cima, aumenta levemente de tamanho e recebe uma sombra.

Esse recurso foi desenvolvido utilizando as propriedades CSS `transition`, `transform` e `box-shadow`, proporcionando uma experiência visual mais dinâmica.
